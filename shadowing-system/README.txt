LG — Consultation Shadowing System (Agent Prototype)

How to use:
1. Open the hosted system from the main site, or keep this folder under the site root.
2. Open "Installation Guide Home.dc.html".
3. Use the on-page buttons — Back (رجوع) and Home (الرئيسية) are in the bottom corner of every page.

Needs an internet connection for fonts. The "assets" folder is included here.
Shared images in img/fridge, img/stains, img/torn, and img/washer are reused
from the parent site's img folder to avoid storing duplicate copies.
