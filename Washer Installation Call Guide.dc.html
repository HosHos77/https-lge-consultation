ملحوظات هامة
في حالة تواصل العميل بعد تسجيل الطلب وأفاد بأنه يريد إضافة موديل (Model) أو رقم إضافي — يتم إضافة ذلك في السيستم ويتم عمل تحديث داخل الاستفسار المفتوح.
في حالة تواصل العميل ويريد إلغاء البلاغ — يتم غلق الاستفسار وتحديث ذلك داخل الاستفسار قبل غلقه.
في حال تواصل العميل معنا بعد الساعة 5:30 مساءً أو يوم الجمعة — سوف نقوم بإبلاغ العميل بأننا سنتابع معه غدًا للتأكد من موعد الزيارة.
ملحوظة خاصة بتيم الاسكادول وكوميبلين
عند غلق الاستفسار يتم اختيار Call code : Call back.

لا يتم التركيب
واحد تركي والتاني غير تركي — لا يتم تركيبهما فوق بعض.
حسب الأبعاد
الموديلان (الغسالة والمجفف) غير تركي — يتم التأكد من الأبعاد؛ لو الأبعاد متطابقة يتم تركيبهما، ولو مختلفة لا يتم التركيب.
العرض والعمق لازم يكونوا نفس المقاس في الغسالة والمجفف.
