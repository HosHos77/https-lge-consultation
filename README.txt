LG — Consultation Shadowing System (Agent Prototype)

How to use:
1. Unzip the folder (keep all files together).
2. Open "Installation Guide Home.dc.html" in Chrome or Edge.
3. Use the on-page buttons — Back (رجوع) and Home (الرئيسية) are in the bottom corner of every page.

Needs an internet connection for fonts. Keep the "assets" and "img" folders next to the pages.
